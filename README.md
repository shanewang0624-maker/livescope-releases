## 1. 首次安装与授权激活

本软件采用 **Ed25519 离线非对称授权（一机一码）**，**需要有效授权码方可使用**：

1. 前往右侧 **Releases** 页面，下载最新版的首装全量包 `LiveScope-Setup-vX.Y.Z.zip`，解压至任意路径（建议 `D:\LiveScope\`，避免系统盘权限与中文符号路径问题）。
2. 双击 **`观播台.vbs`** 启动软件（零黑框，推荐）；若安全软件拦截脚本，改用 `观播台.cmd`。
3. 首次启动会弹出授权窗口：点击复制本机 **机器码** → 联系发行方换取 **授权码** → 粘贴激活即可进入。
   - 机器码由系统 GUID 与硬件信息推导，**不含任何个人数据**，可安全发送。
   - 激活为**离线验签**，不联网、不上传数据，断网可用。

> 授权码与机器码绑定（一机一码）。更换主板/重装系统可能导致机器码变化，需要重新申请。

## 2. 自动更新与升级提醒

- **自动检测**：软件启动时自动向本仓库检查最新 Release 版本。
- **无感升级**：发现新版本时，顶栏右侧亮起 `↑ vX.Y.Z 可更新` 胶囊；点开可查看更新日志、下载并校验 `SHA256`，然后一键重启完成替换（仅替换 `app/` 目录，几十秒完成）。
- **强制更新提示**：若 `manifest.json` 中 `min_required_version` 高于你当前版本，界面顶部会出现不可收起的升级提醒条，请先更新再继续使用。
- **数据安全**：程序文件与用户数据严格隔离。用户数据（授权、登录态、监控库）全部位于 `%LOCALAPPDATA%\LiveScope\`，**升级或重装安装包都不会覆盖或丢失**。
- **网络加速**：如遇 GitHub 拉取缓慢，编辑 `%LOCALAPPDATA%\LiveScope\config.json` 中的 `mirror_prefix` 为加速前缀（例如 `https://ghfast.top/`），保存后重启生效，留空则直连。

### 手动兜底升级

若自动更新因网络或权限失败，可手动升级：

1. 关闭观播台窗口。
2. 下载对应的 `livescope-app-vX.Y.Z.zip` 并解压。
3. 把解压出的 `backend/`、`desktop/`、`frontend/`、`VERSION` 覆盖到安装目录下的 `app/` 中。
4. 重新启动 `观播台.vbs`。数据与授权不受影响。

> 请勿手动覆盖 `runtime/`，除非同时下载了对应版本的首装全量包。

## 3. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 双击 `.vbs` 无反应 | 用 `观播台.cmd`；或检查杀毒软件是否拦截脚本 |
| 提示「需人工验证」 | 点界面「打开直播间」，在弹出浏览器里完成滑块/扫码，回到软件点「我已登录完成」 |
| 实时话术一直为空 | 面板右上角若显示「录音中断」，说明音频拉流失败；检查网络与 `runtime\bin\ffmpeg.exe` 是否被安全软件隔离 |
| 提示授权无效/过期 | 复制机器码联系发行方续期 |
| 更新下载卡住 | 在 `config.json` 配置 `mirror_prefix` 后重启 |
